# Supermarket Sales Analysis

## Project Overview
This project uses Microsoft Excel to analyze supermarket sales data and present useful insights through data analysis, PivotTables, charts, and an interactive-style dashboard.

The project focuses on understanding sales performance, customer contributions, order quantities, order sizes, and shipping performance.

## Project Objectives
- Inspect and clean the sales dataset.
- Calculate key sales performance metrics.
- Analyze monthly sales revenue.
- Compare sales revenue across customers.
- Examine order sizes and quantities purchased.
- Analyze shipping duration.
- Create charts and a dashboard to communicate findings.

## Tools Used
- **Microsoft Excel:** Data cleaning, formulas, PivotTables, charts, and dashboard creation.
- **Microsoft Word:** Project documentation and reporting.

## Dataset Description
The dataset contains **70 sales records** with information including:
- Order number
- Order date
- Customer name
- Ship date
- Retail price
- Order quantity
- Tax
- Total sales
- Shipping days
- Order size category
- Order month

## Analysis Performed

### 1. Data Inspection and Cleaning
Inspected the dataset, checked data consistency, and prepared the data for analysis.

### 2. Sales Metrics
Calculated key metrics, including total revenue, total orders, total quantity sold, average order value, highest sale, and lowest sale.

### 3. Monthly Sales Analysis
Compared revenue across months to identify sales patterns.

### 4. Customer Sales Analysis
Compared revenue generated by different customers.

### 5. Order Size and Quantity Analysis
Examined revenue by order size category and order quantity.

### 6. Shipping Performance
Analyzed the number of orders by shipping duration.

### 7. Sales Dashboard
Created a dashboard combining key performance indicators and charts to provide an overview of sales performance.

## Project Files
- Supermarket_Sales_Analysis.xlsx — Excel workbook containing the dataset, calculations, analysis, PivotTables, charts, and dashboard.
- Supermarket_Sales_Report.pdf — Report documenting the project methodology, findings, and recommendations.

This project demonstrates how Microsoft Excel can transform raw supermarket sales data into meaningful information. The analysis supports better understanding of sales performance, customer contributions, order patterns, and shipping operations.
